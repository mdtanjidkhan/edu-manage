# EduManage

A modern **School Management System** built with Next.js to manage academic and administrative activities for Admins, Teachers, and Students.

## Key Features

* Role-based dashboards for **Admin, Teacher & Student**
* Authentication with **Better Auth**
* Student & teacher management
* Attendance and marks management
* Class routine and notices
* Fee management
* Online admission application
* Responsive and user-friendly UI

## Tech Stack

**Next.js · React · Tailwind CSS · DaisyUI · Better Auth · REST API · MongoDB**

## AI Assistance

**Gemini & ChatGPT** — used as development assistants for debugging, problem-solving, code review, and exploring implementation approaches.

## Architecture

**Next.js → Express.js REST API → MongoDB**
